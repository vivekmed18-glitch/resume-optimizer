# Resume.AI - Resume Builder & Recruiter/ATS Analyzer

A premium, local-first web application designed to optimize resume drafts against a target job description in three screening stages: ATS Review, Recruiter 7-Second Review, and Hiring Manager Review.

## Technology Stack (Vanilla Core)
*   **Structure**: Semantic HTML5 (with ARIA roles)
*   **Styling**: Vanilla CSS3 (Custom properties, grid/flexbox, custom scrollbars, and print layouts)
*   **Logic**: ES6 JavaScript (Native DOM events, state binding, and modal focus constraints)

## Local Setup
1. Clone or copy the folder contents.
2. Run a local server (e.g. `python -m http.server 8080`) and navigate to `http://localhost:8080/index.html`.
3. To print or export to PDF, press `Ctrl+P` (or `Cmd+P` on Mac).
